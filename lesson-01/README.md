# שיעור 1 · פלט מובנה ובדיקה מול סט ידוע

## מטרה

לחייב מודל שפה להחזיר JSON במבנה קבוע, ולבדוק את הסיווג מול 10 פניות שהתוצאה שלהן ידועה מראש.

## כלים

Google AI Studio עם מודל 3.8 Flash, ו-Google Sheets ליומן הבדיקה.

## נתוני בדיקה

10 פניות של לקוחות לחנות מקוונת לדוגמה, לכל אחת קטגוריה ודחיפות צפויות: [test-data.csv](test-data.csv). שתי פניות קשות בכוונה: פנייה 9 עוסקת במשלוח אבל נשלחה לפני הזמנה, ופנייה 10 מתחילה בהחזרה אבל מבקשת כסף.

## מה נבדק

| גרסה | מה השתנה | קטגוריה | דחיפות | JSON תקין |
|---|---|---|---|---|
| v1 | JSON מבוקש במילים בהודעה | 10/10 | 10/10 | לא |
| v2 | Structured output עם סכמה | 10/10 | 10/10 | כן |
| v3 | הרצה חוזרת של v2, בדיקת יציבות | 10/10 | 10/10 | כן |

היומן המלא: [results-log.csv](results-log.csv)

## תוצאה נמדדת

קטגוריה 10/10, דחיפות 10/10, JSON תקין, ותוצאה זהה ב-2 מתוך 2 ריצות.

## מה למדתי

- בקשה ל-JSON בהודעה לא מבטיחה מבנה. ב-v1 התשובה הגיעה עטופה בסימון קוד, וב-AI Studio הסימון מוסתר בתצוגה הרגילה ונראה רק במצב עריכה.
- Structured output עם סכמה מחייב את המבנה. enum מגביל שדה לרשימה סגורה של ערכים, כך שהמודול הבא באוטומציה תמיד מקבל ערך שהוא מכיר.
- בודקים כל גרסה בצ׳אט חדש, ובלי התשובות הצפויות בהודעה. אחרת המודל מעתיק ולא מסווג.

## מגבלות

Temperature לא זמינה במודל 3.8 Flash, ולכן היציבות נבדקה בשתי ריצות בלי שינוי טמפרטורה.

## הפרומפט

כללי הסיווג, שהודבקו ב-System instructions:

```
אתה מסווג פניות של לקוחות לחנות מקוונת לכלי בית.
לכל פנייה קבע קטגוריה אחת ודחיפות אחת.

קטגוריות:
משלוח: הזמנה שכבר בוצעה ולא הגיעה, איחור, שינוי כתובת.
החזרה: בקשה להחזיר או להחליף מוצר תקין.
תשלום: כל מה שקשור לכסף: חיוב, זיכוי, החזר כספי, חשבונית.
תקלה במוצר: מוצר שהגיע פגום, שבור או לא עובד.
שאלה מקדימה: שאלה של מי שעוד לא הזמין, גם אם היא על משלוח.

דחיפות:
גבוהה: חיוב כפול או שגוי, או מוצר שמסוכן לשימוש (חשמל, אש, חום).
נמוכה: שאלה מקדימה.
רגילה: כל השאר.

הנימוק: משפט אחד, עד 10 מילים.
```

הסכמה, שהודבקה ב-Structured outputs:

```json
{
  "type": "object",
  "properties": {
    "results": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "id": { "type": "integer" },
          "category": { "type": "string", "enum": ["משלוח", "החזרה", "תשלום", "תקלה במוצר", "שאלה מקדימה"] },
          "urgency": { "type": "string", "enum": ["גבוהה", "רגילה", "נמוכה"] },
          "reason": { "type": "string" }
        },
        "required": ["id", "category", "urgency", "reason"]
      }
    }
  },
  "required": ["results"]
}
```
