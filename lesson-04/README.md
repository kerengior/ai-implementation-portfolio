# שיעור 4 · HTTP Request: קריאה ל-API ציבורי

## מטרה
לשלוף נתונים מ-API ציבורי בתוך n8n, לפרק את התשובה לפריטים בודדים ולכתוב אותם לגיליון.

## כלים
- n8n Cloud
- Hebcal API, לוח השנה העברי. API ציבורי שלא דורש מפתח.
- Google Sheets

## הזרימה
```
הפעלה ידנית → HTTP Request (GET ל-Hebcal) → Split Out (שדה items) → Google Sheets (הוספת שורה)
```

| צומת | תפקיד |
|---|---|
| HTTP Request | שולח בקשת GET ומקבל תשובת JSON אחת, שמכילה מערך של כל המועדים בשנה |
| Split Out | מפרק את המערך `items` ל-item נפרד לכל מועד |
| Google Sheets | כותב שורה לכל מועד בטאב "פלט שיעור 4": תאריך, חג, יום טוב |

## נתוני בדיקה
שנה קבועה (2026), ותוצאה צפויה: רשימת החגים והמועדים ותאריכיהם.

## מה נבדק
- כל המועדים מהרשימה הצפויה מופיעים בגיליון.
- התאריכים נכונים.
- עמודת "יום טוב" מסומנת רק בימים שהם יום טוב.

## תוצאה נמדדת
- **37 מתוך 37** מועדים נכתבו לגיליון, שורה לכל מועד.
- התאריכים תואמים לרשימה הצפויה.

## מה למדתי
- **item אחד מול הרבה items:** קריאת API מחזירה תשובה אחת, ו-n8n הופך אותה ל-item אחד. כשהנתונים נמצאים בתוך מערך, צריך Split Out כדי לעבד כל רשומה בנפרד. בלי הפיצול, נכתבת לגיליון שורה אחת.
- **גרירת שדות:** גרירה מתצוגת ה-Schema יוצרת ביטוי כמו `{{ $json.date }}`, שרץ על כל item. התצוגה המקדימה מציגה רק את ה-item הראשון.
- **שדה חסר = `undefined`:** Hebcal מחזיר את השדה `yomtov` רק בימים שהם יום טוב. כדי שבכל שורה יופיע ערך, השתמשתי בביטוי:
  `{{ $json.yomtov ? 'כן' : 'לא' }}`
- **GET מול POST:** כאן השתמשתי ב-GET, כי רק שלפתי מידע. קריאה למודל שפה תהיה POST, עם גוף בקשה ומפתח API בכותרת.

## מגבלות
- הזרימה מופעלת ידנית ועל שנה קבועה, ואין בה תזמון.
- אין טיפול בשגיאות. אם ה-API לא זמין, הזרימה נכשלת.
