# שיעור 10 · כלי שני: דיווח על מטלה שבוצעה

פרויקט B · עוזר מטלות הבית · שיעור 2 מתוך 5

## מה נבנה

סוכן AI ב-n8n עם שני כלים, שניהם על Google Sheets:

- `read_tasks` קורא את רשימת המטלות.
- `mark_task_done` מסמן מטלה כבוצעה, לפי `task_id`.

ילד כותב בשפה חופשית שהוא סיים מטלה. הסוכן קורא את הגיליון, מוצא את המטלה של אותו ילד, ומעדכן את השורה. המודל ממלא רק את `task_id`. הסטטוס ("בוצע") קבוע, והתאריך נקבע לפי השעון של n8n.

## תוצאה

**5 מתוך 5 עדכונים נכונים בגיליון.** בכל עדכון סומנה המטלה הנכונה, אצל הילד הנכון ועם התאריך של היום, ואף שורה אחרת לא השתנתה.

| הודעה | מטלה שסומנה |
|---|---|
| אני נועה, קיפלתי את הכביסה | 7 |
| זה איתי, מילאתי מדיח | 5 |
| מאיה פה, ניגבתי את השולחן | 9 |
| איתי: הוצאתי מחזור | 11 |
| אני מאיה, פיניתי מדיח | 12, ולא 1 (המטלה של נועה בעלת אותו שם) |

## ממצאים

1. **שם של כלי ושם של שדה שהמודל ממלא חייבים להיות באנגלית.** ה-API של המודל מקבל בשמות של כלים ופרמטרים רק אותיות באנגלית, ספרות, קו תחתון ומקף. n8n מחליף כל תו אחר ב-`_`, ולכן שני כלים עם שמות בעברית קיבלו את אותו שם. התיקון: שמות הכלים וכותרות הגיליון הוחלפו לאנגלית. הערכים נשארו בעברית.
2. **Defined by agent הופך את שם העמודה לשם הפרמטר.** עמודה בשם "מס׳" נשלחה למודל כפרמטר `___`.
3. **ביטוי `$fromAI` בתוך שדה Description יוצר פרמטר כפול.** Description צריך להכיל טקסט רגיל בלבד.
4. **ירידת שורה אחרי `}}` נכתבת לתא כחלק מהערך.**
5. **הסוכן דיווח "רשמתי" לפני שהכלי הצליח.** את ההצלחה בודקים בלוג ובגיליון, ולא לפי התשובה בצ׳אט. המקרה ייכנס לניסיונות השבירה בשיעור 13.
