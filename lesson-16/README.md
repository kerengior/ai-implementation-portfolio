# שיעור 16 · ציטוט מקור, ניסוי Limit והשוואה

פרויקט C · שאלות על מסמכי בניית הבית · שיעור 3 מתוך 3 (סוגר את הפרויקט)

## מה נבנה

עד עכשיו המקור נראה רק ב-Logs. משתמש רגיל לא פותח Logs, ולכן הסוכן כותב עכשיו את המקור בתוך התשובה.

השינויים בזרימה משיעור 15:

- **ציטוט מקור ב-System Message** בתבנית קבועה של שתי שורות.
- **Limit ירד מ-4 ל-2**, כדי שהאחזור באמת יבחר בין הקטעים.

```
בסוף כל תשובה הוסף בדיוק את שתי השורות הבאות:
מקור: <שם הקובץ מה-metadata>
ציטוט: "<עד 15 מילים, מועתקות מילה במילה מהקטע שנשלף>"
אם התשובה נשענת על כמה מסמכים, חזור על שתי השורות לכל מסמך.
אם לא נמצא קטע רלוונטי, כתוב "לא נמצא במסמכים" בלי מקור ובלי ציטוט.
```

## איך נבדק

3 שאלות מייצגות מתוך ה-10: עובדה אחת (1), שאלה ששני מסמכים עונים עליה (7), ושאלה מחוץ למסמכים (10). כל ציטוט נבדק מול הקטע שנשלף ב-Logs.

## תוצאות

| שאלה | תשובה | מקור | ציטוט מילולי | הציטוט מוכיח את התשובה |
| --- | --- | --- | --- | --- |
| 1 · סכום כולל מע״מ | ✓ | ✓ | ✓ | ✓ |
| 7 · הובלה, ספק ב׳ | ✓ | ✓ | ✓ | ✓ |
| 7 · הובלה, ספק א׳ | ✓ | ✓ | ✓ | ✗ רצף מספרים בלבד |
| 10 · לא במסמכים | ✓ | אין, כנדרש | אין, כנדרש | — |

**ניסוי Limit = 1 (שאלה 7 ו"משלוח", בצ׳אט נקי):** ספק א׳ נענה נכון (800). אצל ספק ב׳ נשלף רק סעיף התנאים הכלליים, והסוכן ענה "ההובלה לא כלולה". במסמך יש שורה של 600 ש״ח עלות הובלה, אבל הקטע שבו היא מופיעה לא נשלף. **התשובה שגויה, מגיעה עם ציטוט מילולי, ואין בה שום סימן שחסר מידע.**

## ממצאים

1. **ציטוט מילולי לא מוכיח שהתשובה נכונה.** במסמך שהחילוץ שלו משובש, הציטוט היה רצף מספרים, והמודל הסיק בעצמו את הקשר בין המספר לפריט.
2. **תבנית קבועה עובדת טוב יותר מתיאור.** בגרסה הראשונה ביקשתי ציטוט בתיאור חופשי, והמודל החזיר רק שם קובץ. עם תבנית של שתי שורות, הציטוט הופיע בכל התשובות.
3. **Limit קטן מדי מייצר תשובה שגויה שנראית מבוססת.** בוחרים Limit לפי סוג השאלות: בשאלות השוואה, לפחות מספר המסמכים שמשווים, ועוד מרווח.
4. **זיכרון השיחה מזהם בדיקות.** שאלה שחוזרת באותה שיחה יכולה לקבל מידע מתשובה קודמת ולא מהאחזור. כל שאלת בדיקה נשאלת בשיחה נקייה.
5. **Webhook לא רשום.** בחלון הבדיקה התקבלה השגיאה `webhook is not registered`, כי כתובת הבדיקה פגה. בייצור משתמשים בכתובת Production של זרימה פעילה, והשגיאה הזו לא מגיעה ל-Error Workflow, ולכן נדרש ניטור חיצוני.
