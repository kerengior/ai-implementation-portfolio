# פרויקט B · עוזר מטלות הבית

## הבעיה

במשפחה עם שלושה ילדים יש רשימת מטלות שבועית. ההורים צריכים לזכור מי עשה מה, הילדים שואלים כל יום מה נשאר להם, והרשימה על המקרר לא מתעדכנת.

## הפתרון

סוכן AI בעמוד צ׳אט שנפתח מהטלפון. כל ילד שואל מה המטלות שלו ומדווח כשסיים, הסוכן מעדכן גיליון Google, וההורים יכולים לשאול "מי סיים מה השבוע?".

```
עמוד צ׳אט (סיסמה) ──► AI Agent (Gemini) ──► תשובה
                          │  ├─ read_tasks      קריאת המטלות מהגיליון
                          │  ├─ mark_task_done  סימון מטלה כבוצעה + תאריך
                          │  └─ Simple Memory   זיכרון לכל שיחה
                          │
                          └─(Error)──► טאב שגיאות + הודעה "נסו שוב"
```

**החלטות עיקריות:**

- **סוכן עם כלים, לא זרימה קבועה.** הודעות של ילדים חופשיות ("זרקתי את הזבל", "סיימתי את המדיח"). המודל מתאים אותן למטלה בגיליון ובוחר איזה כלי להפעיל.
- **קודם קוראים, אחר כך כותבים.** הסוכן מוצא את ה-task_id בגיליון לפני כל סימון, ולא מנחש אותו.
- **כשלא ברור, שואלים.** אם יותר ממטלה אחת מתאימה, הסוכן מפרט את האפשרויות ולא בוחר בעצמו.
- **גבולות שהמערכת אוכפת קודמים לגבולות בהוראות.** לסוכן אין כלי מחיקה, וכלי הכתיבה יכול רק לסמן "בוצע".
- **הערוץ נפרד מהסוכן.** וואטסאפ תוכנן ונדחה בגלל הגבלה בחשבון Meta. המעבר בעתיד ידרוש רק החלפת טריגר.

## מה הייתי משנה

1. **זהות שהמערכת קובעת.** היום הסוכן יודע מי כותב רק לפי מה שהילד כותב. כל ילד יכול להתחזות לאח. הפתרון: קישור וסיסמה נפרדים לכל ילד (מתוכנן לשיעור 22).
2. **כשל שהסוכן "בולע" צריך להגיע למנהל.** כשהכלי נכשל, הסוכן עונה לילד "לא הצלחתי לשמור", אבל הריצה נחשבת תקינה ואף אחד לא יודע. צריך שהסוכן יחזיר תוצאה מובנית שהזרימה מנתבת לפיה, בדיקה מול הגיליון, והתראה.
3. **זמן תגובה.** קריאה איטית ל-Gemini (עד יותר מדקה) גורמת לצ׳אט להפסיק לחכות. אין בצומת הגדרה של זמן המתנה מקסימלי.
4. **סט בדיקה גדול יותר.** כל שיעור נבדק על 5–10 הודעות. ילדים אמיתיים כותבים עם שגיאות כתיב, קיצורים ואימוג׳ים.
